운영자 로그인

진행 회차

결제가 확인된 참가자예요. 프로필 자료 확인을 마치면 참가 확정 후 QR을 발급할 수 있어요.

개인 QR을 한 번에 준비해요

참가 확정·결제 완료인 분에게 발급해요. 기존 QR은 그대로 두고 미발급자만 새로 만들어요. 발급 직후 저장해주세요.

메모·매칭 설정

상대 번호 수만큼 1호부터 메모가 생겨요. 남녀 인원이 다르면 각각 설정해주세요. 1~13개까지 가능해요.

여성 1호 ~ —호

남성 1호 ~ —호

발급 버튼을 누르면 기존 QR에도 설정이 적용돼요. 이미 열어둔 메모장은 새로고침해주세요. 상대가 선택 한도보다 적으면 상대 수까지만 선택할 수 있어요. 이미 쓴 메모나 제출한 선택이 가려지는 변경은 할 수 없어요.

기존 QR과 접속은 종료돼요. 작성된 메모와 매칭 선택은 유지해요.

저장한 파일을 열면 QR을 한 번에 인쇄할 수 있어요. 개인 QR은 해당 참가자에게 전달해주세요.

서로 선택한 매칭 결과

현재 저장된 선택을 기준으로 대조해요. 문자를 보내기 전에 회차를 새로고침해 제출 현황을 확인해주세요.
